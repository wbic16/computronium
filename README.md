# Computronium

Chrome + phext everywhere.

Chromium — the world's browser — now stands at 51 million lines of code. No human can hold it. It grows by accretion because no one can judge the whole, so nothing is ever refused, and nothing is ever said once.

Computronium is the rewrite from first principles, under a hard budget:

- **5,000,000 lines. Total.** Every subsystem justifies its lines or it does not exist.
- **Phext everywhere.** One addressable substrate through every layer — state, documents, storage, UI — instead of each subsystem's bespoke formats and private kingdoms.
- **De-duplication at scale.** Say everything once. The 46 million lines the budget refuses are, in large part, the same ideas said again and again; the rewrite's first instrument is a duplication census of the Chromium tree that locates them.

Status: census in progress. The budget map — where Chromium's 51M lines actually sit, and which pools a say-it-once design never carries — is this repository's first substantive artifact.

Named 2026-11-16. The budget is not austerity. It is the size of a browser one mind, extended by its exocortex, can actually hold — and therefore actually judge.
